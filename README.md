# Madhura Karangale — Portfolio

A personal portfolio website for **Madhura Karangale**, an aspiring Data Analytics Engineer.

## 🌐 Live Site
[View Portfolio](https://madhurakarangale.github.io/Portfolio)

## 📁 Project Structure
```
Portfolio/
├── index.html        # Main HTML (photo embedded as Base64)
├── css/
│   └── styles.css    # All styles & theme
├── js/
│   └── script.js     # Interactions & animations
└── .gitignore        # Excludes local assets
```

## 🚀 Hosting on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Source: **Deploy from branch** → `main` → `/ (root)`
4. Click **Save** — your site will be live in ~1 minute

## 🔒 Privacy Note
The profile photo is embedded directly in `index.html` as a Base64 data URI.  
The `assets/` folder is excluded from the repository via `.gitignore`.
